STEP 6: COMPUTE AVAILABILITY FEATURES
┌─────────────────────────────────────────────────────────────────────────┐
│ features/availability.py                                                │
│ Function: compute_availability_features(players)                        │
│                                                                          │
│ 1. Sort players by baseline_minutes (descending)                        │
│    → Giannis (33.0), Middleton (32.5), ...                              │
│                                                                          │
│ 2. Take top 2 players (the stars)                                       │
│                                                                          │
│ 3. For each of top 2:                                                   │
│      missing = max(0, baseline_minutes - projected_minutes)             │
│                                                                          │
│    Giannis:                                                             │
│      missing = max(0, 33.0 - 25.0) = 8.0 minutes ← INJURY IMPACT        │
│                                                                          │
│    Middleton:                                                           │
│      missing = max(0, 32.5 - 32.5) = 0.0 minutes ← Healthy              │
│                                                                          │
│ 4. Sum the missing minutes:                                             │
│      minutes_missing_top2 = 8.0 + 0.0 = 8.0                             │
│                                                                          │
│ 5. Check if any star is OUT (projected < 0.001):                        │
│      Giannis projected = 25.0 > 0 → star_out = 0                        │
│      If he were OUT (projected=0) → star_out = 1                        │
│                                                                          │
│ 6. Sum usage of top 2:                                                  │
│      usage_share_top2 = 0.32 + 0.28 = 0.60                              │
│                                                                          │
│ Return AvailabilityFeatures(                                            │
│   minutes_missing_top2=8.0,     ← THE FEATURE WE WANT!                  │
│   star_out=0,                                                           │
│   team_weighted_ts=0.58,                                                │
│   usage_share_top2=0.60                                                 │
│ )                                                                       │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓

┌─────────────────────────────────────────────────────────────────────────┐

│   availability_away = AvailabilityFeatures(0.0, 0, 0.53, 0.0)           │
│                                                                          │
│ x_home = {                                                              │
│   "edge": 4.08,                                                         │

│   ...                                                                   │

│ }                                                                       │
